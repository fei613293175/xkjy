# 星矿纪元 V1.3.0 游戏视觉重建与像素级开发规范

## 一、设计方向

V1.3.0 采用“深空矿业·稳重游戏化”视觉语言：

- 深海军蓝和黑蓝作为背景；
- 金色与橙色只用于收益、奖励和主操作；
- 蓝色用于功能操作；
- 紫色用于能源、稀有状态和会员权益；
- 青色用于局部科技强调，不再用粗青色边框包围所有组件；
- 游戏首页以矿场、4×4 棋盘、矿机、收益和场景纵深为主体；
- 项目、商城、集市和个人中心保留游戏皮肤，但信息密度优先；
- 登录、支付、实名、提现等安全流程优先保证可读性和确定性。

## 二、三套页面外壳

### GameSceneShell

适用于矿场、合成、离线收益、解锁、补给箱等页面。具备完整场景背景、游戏 HUD、棋盘或演出中心。

### GameBusinessShell

适用于项目、商城、集市、钱包、邀请、会员和个人中心。使用低干扰深空背景与紧凑面板，禁止大面积无意义空白。

### SecureFlowShell

适用于登录注册、支付、实名、提现和账号安全。使用克制的深色面板、明确步骤、固定按钮和完整安全区。

## 三、基准尺寸

```text
设计基准：360×760dp
输出基线：1080×2280px
密度：3×
真实系统状态栏：由 Android 管理
预览状态栏：只存在于效果图，不开发
```

核心尺寸见 `03_SPECS/DESIGN_TOKENS_GAME_V130.json`。

## 四、防变形规则

1. 主按钮高度固定 42dp，紧凑按钮 34dp。
2. 按钮宽度由父容器和布局权重决定，不由文字长度决定。
3. 完整按钮 PNG 不得用于可变宽按钮；应使用 Compose Shape、Brush 或合规 9-patch。
4. 文字默认单行，必要时缩短文案或省略，禁止撑高按钮。
5. 矿机使用 `ContentScale.Fit`；不得 `FillBounds`、非等比缩放或裁切。
6. 图标使用固定 18/22/26/35dp 档位，保持比例。
7. 项目缩略图固定 16:9，允许 `Crop`，但不得拉伸。
8. 含底部导航的滚动容器保留至少 76dp 底部空间。
9. 一级 Tab 根页不显示顶部返回按钮。
10. 模态框必须完全位于安全视口，遮罩覆盖页面内容区。

## 五、状态差异

不同 State ID 必须具有真实可见差异。例如：

- `DEFAULT` 与 `CLAIMABLE`：领取按钮、收益数值和气泡状态不同；
- `DEFAULT` 与 `OFFLINE`：显示非阻断网络提示，保留原有内容；
- `SUBMITTING`：按钮进入加载且表单锁定，不重复出现第二个大型状态面板；
- `VERIFYING/SUCCESS/FAILURE/RECAPTURE`：图标、标题、说明和操作按钮均不同；
- `PROCESSING/SUCCESS/FAILURE`：提现状态和可执行操作不同。

禁止只改文件名而复制完全相同画面。

## 六、像素还原流程

1. 读取 Page Spec 与业务状态。
2. 对照同名 PNG 确认结构、层级和状态。
3. 使用同名 HTML 和 `styles_v130.css` 获取精确尺寸关系。
4. 使用 V1.3.0 Token 和资源实现 Compose 组件。
5. 在 360×760dp、390×844dp、412×915dp 三档真机/模拟视口检查响应式表现。
6. 生成 Compose 真机截图。
7. 与 1080×2280 基线进行结构和像素差异比较。
8. 人工检查文字、按钮、矿机、导航、滚动底部和模态框。

## 七、视觉验收阈值

```text
主要组件边界偏差 ≤ 2dp
文字基线偏差 ≤ 1dp
按钮高度偏差 = 0dp
图标尺寸偏差 ≤ 1dp
核心页面全图差异 ≤ 3%
横向溢出 = 0
文案裁切 = 0
非等比拉伸 = 0
底部导航遮挡 = 0
根页面错误返回按钮 = 0
```

## 八、渲染工具

HTML 效果图只允许 Chromium/Playwright。禁止 WeasyPrint、wkhtmltopdf 和 PDF 转 PNG，因为这些工具不能可靠复现复杂 Flex、绝对定位、固定导航和模态框布局。
