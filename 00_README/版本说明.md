# 星矿纪元 V1.3.0 游戏视觉重建版

## 版本目的

V1.3.0 针对 V1.2.0 出现的按钮拉伸、元素越界、模态框错位、背景结构穿透、根页面返回键错误、假状态栏和页面过度 App 化问题，重新建立 Android 视觉系统与可验证渲染链路。

## 保留内容

- V1.1.0 的全部业务、后端、数据库和接口合同；
- 私有母版中的邮箱、Cloudflare R2、实名认证、XApay、人工扫码和支付宝提现能力；
- 36 级矿机、主副积分、积分集市、项目推广、会员、二级提成、红包卡和提现模式；
- 管理后台与 H5 功能范围。

## V1.3.0 替换内容

- 132 张 Android 页面状态图；
- 132 份同名 HTML；
- `styles_v130.css`；
- 36 级矿机新素材；
- 游戏背景、面板、图标、项目缩略图和品牌素材；
- Design Token、伸缩规则、Compose 参考组件；
- Chromium 渲染脚本、DOM 越界检测和状态重复检测；
- Android Page Spec 的视觉基线、尺寸和根导航规则。

## 验证结论

V1.3.0 Android 基线已通过自动验证：

- 132/132 页面状态 PNG 存在；
- 132/132 HTML 存在；
- 所有 PNG 为 1080×2280；
- 无横向溢出；
- 无按钮裁切或异常高度；
- 无元素超出视口；
- 模态框位于安全视口；
- 一级 Tab 根页无返回按钮；
- 同一 Page ID 的关键状态不存在完全相同截图。
