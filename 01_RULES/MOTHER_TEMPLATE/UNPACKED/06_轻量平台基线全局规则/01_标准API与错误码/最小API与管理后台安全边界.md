# 最小 API 与管理后台安全边界

该规范属于统一 API 基线的一部分，不新增重型安全平台。

## API

- 正式业务接口只允许 HTTPS；
- CORS 使用明确域名白名单，携带凭据时禁止 `*`；
- 每个受保护接口在后端执行身份、角色、对象和必要字段权限校验；
- 隐藏前端按钮不能替代后端权限；
- 请求字段、长度、枚举、文件类型和大小在后端重新校验；
- 原始异常、SQL、堆栈和第三方密钥不得返回客户端；
- 匿名敏感接口和高风险写接口必须频控并返回稳定错误码与 `Retry-After`。

## 管理后台登录和会话

- 管理员不开放公共注册；
- 管理员身份建议与普通用户账号隔离；
- 每次登录提交必须通过自研图形验证码；
- 使用 Cookie 会话时必须设置 `Secure`、`HttpOnly` 和合理 `SameSite`；
- Cookie 鉴权的写请求必须防 CSRF；
- 默认空闲 30 分钟失效、绝对会话 12 小时，可在后台按项目调整；
- 密码失败、频控、会话创建、退出、强制下线和权限变更必须审计。

## 轻量边界

首版不强制采购 WAF、设备指纹、风险评分或多因素认证平台；项目存在更高风险时再按明确需求启用。
