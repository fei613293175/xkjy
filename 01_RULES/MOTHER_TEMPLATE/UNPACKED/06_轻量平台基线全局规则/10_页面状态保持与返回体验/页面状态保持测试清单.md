# 页面状态保持测试清单

- [ ] 列表滚动到较深位置，进入详情再返回，仍停留在同一条目和偏移；
- [ ] 搜索词、筛选、排序、Tab、分页/游标保持；
- [ ] 折叠、展开、选中和批量选择状态按页面合同保持；
- [ ] 长表单进入子页面或系统选择器后返回，草稿不丢失；
- [ ] 底部主导航切换到其他 Tab 再返回，原 Tab 的列表位置和子页面栈保持；
- [ ] App 切后台再回来不重新创建页面；
- [ ] 支付 App、相机、相册、文件选择器和权限页面返回后上下文保持；
- [ ] 返回时没有全屏白屏、无意义骨架屏或先清空再加载；
- [ ] 返回不会重复发起相同全量网络请求；
- [ ] 详情修改后只局部更新对应条目，并保持位置；
- [ ] 删除条目后停留在邻近合理位置；
- [ ] 管理后台浏览器返回保留筛选、页码、表格列和滚动位置；
- [ ] 允许重置的页面均在 Page Spec 中记录例外原因；
- [ ] 进程重建后恢复可安全保存的关键状态，敏感字段不违规落盘。
