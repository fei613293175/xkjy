# 图形安全验证码测试清单

- [ ] 登录、注册、找回、发送验证码和后台登录按规则弹出验证码；
- [ ] 表单在弹窗打开、刷新、错误和关闭后不丢失；
- [ ] 正确验证后自动继续原业务；
- [ ] 错误、过期、刷新和超过最大尝试次数处理正确；
- [ ] 刷新后旧 challenge 失效；
- [ ] ticket 只能使用一次，重放被拒绝；
- [ ] ticket 用途、匿名会话和目标不匹配时被拒绝；
- [ ] 直接绕过弹窗调用受保护业务接口被后端拒绝；
- [ ] 响应、日志、数据库和管理后台均不出现正确答案；
- [ ] 验证码图片不写入对象存储或用户设备共享目录；
- [ ] IP、设备、账号和目标频控命中后返回正式业务提示及 `Retry-After`；
- [ ] 管理后台可查看统计和配置，但不能查看答案；
- [ ] 项目无缓存时数据库短期存储与过期清理可用；
- [ ] 不存在任何第三方验证码 SDK、网页或密钥依赖。
