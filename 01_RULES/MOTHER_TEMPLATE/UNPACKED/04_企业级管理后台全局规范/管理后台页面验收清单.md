# 管理后台页面验收清单

- [ ] 菜单结构与项目业务一致，未启用模块不显示
- [ ] 每页有 Page ID、规格、实际 UI 数值、效果图和源文件
- [ ] 列表支持必要的搜索、筛选、排序、分页和状态
- [ ] 详情包含关联数据、时间线和操作入口
- [ ] 操作按钮真实绑定后端，不是假按钮
- [ ] 高风险操作有二次确认和原因
- [ ] 配置项有默认值、校验、说明、权限和历史
- [ ] 第三方接口有状态、测试、调用日志和错误信息
- [ ] 支付有异常订单、回调、补单和退款记录
- [ ] 实名有照片/视频、结果、失败原因和人工处理
- [ ] 权限覆盖菜单、页面、操作、字段和数据范围
- [ ] 敏感字段掩码且查看受控
- [ ] 所有关键操作写审计日志
- [ ] 加载、空、错误、无权限状态完整
- [ ] 页面风格、字号、圆角、间距和组件统一
- [ ] 运营人员无需直接修改数据库即可完成日常管理


## 登录与安全

- [ ] 管理后台登录使用后端自研图形验证码；
- [ ] 可验证直接绕过验证码的登录请求被拒绝；
- [ ] 登录频控、会话超时、强制下线和失败日志可用；
- [ ] 不存在公开管理员注册入口。

- [ ] 从列表进入详情再返回时保留筛选、排序、页码、表格列和滚动位置；
- [ ] 浏览器返回无整页白屏或默认第一页重载；
- [ ] 菜单、表格操作和状态图标均登记 Icon ID；
- [ ] 不存在汉字、字母、数字、Emoji 或 Icon Font 代图标。
