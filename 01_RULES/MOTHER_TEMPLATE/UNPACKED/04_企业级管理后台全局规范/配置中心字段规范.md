# 配置中心字段规范

每个配置项至少包含：

| 字段 | 说明 |
|---|---|
| config_key | 稳定机器键，不随中文名称变化 |
| name | 后台中文名称 |
| module | 所属模块 |
| type | boolean/int/decimal/string/enum/json/secret |
| default_value | 推荐默认值 |
| current_value | 当前生效值 |
| unit | 元、分钟、次、MB 等 |
| min/max | 数值范围 |
| options | 枚举可选值 |
| description | 运营人员可理解的说明 |
| sensitive | 是否敏感 |
| permission | 查看和修改权限 |
| effective_scope | 全局/项目/用户组等 |
| effective_time | 立即/定时/重启后 |
| validation | 保存校验 |
| test_action | 是否支持测试连接 |
| change_reason | 修改时是否必填 |
| version | 配置版本 |
| updated_by/at | 修改人和时间 |

密钥配置默认掩码，保存空值不代表清空；清空必须使用单独操作并二次确认。
