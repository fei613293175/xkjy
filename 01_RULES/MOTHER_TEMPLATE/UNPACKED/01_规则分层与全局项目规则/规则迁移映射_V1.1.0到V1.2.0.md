# V1.1.0 → V1.2.0 规则迁移映射

## 一、保持不变

- G-001~G-035 原编号和含义保持不变；
- M-ID、M-PAY、M-STORAGE、M-EMAIL 规则保持不变；
- 四项固定测试配置原值保留；
- Page ID、效果图、企业级后台、服务器、真机和交付规则继续生效。

## 二、新增全局规则

| 新规则 | 内容 |
|---|---|
| G-036 | 统一 API 协议与错误码 |
| G-037 | Android 签名、版本与最小更新 |
| G-038 | 数据库迁移、基础备份与恢复 |
| G-039 | 结构化日志与健康检查 |
| G-040 | 最小配置中心与紧急开关 |
| G-041 | 关键流程幂等、有限重试与补偿 |
| G-042 | 依赖锁定与可重复构建 |
| G-043 | 自研图形验证码与匿名接口防刷 |
| G-044 | 复杂度预算与触发式开发 |
| G-045 | 增量验收与阶段全量回归 |

## 三、新增模块

新增 `M-ACCOUNT-001~M-ACCOUNT-012`，仅项目存在用户注册、登录、找回密码或会话时启用。账号模块强制依赖 G-043 自研图形验证码；使用邮箱验证码时自动启用邮箱模块。

## 四、目录调整

V1.2.0 新增 `06_轻量平台基线全局规则` 和 `07_可选平台复用模块`，原域名、Codex、测试、数据和原始资料目录顺延为 08~12。项目生成器不得继续引用 V1.1.0 旧路径。

## 五、兼容原则

执行中的旧项目可以锁定 V1.1.0。新项目统一采用 V1.2.0，禁止同一项目混用两套 G 规则范围和目录路径。
