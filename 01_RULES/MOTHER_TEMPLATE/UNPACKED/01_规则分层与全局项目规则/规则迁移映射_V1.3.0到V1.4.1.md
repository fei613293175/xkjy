# V1.3.0 到 V1.4.1 规则迁移映射

## 必须升级

| V1.3.0 | V1.4.1 | 处理 |
|---|---|---|
| 旧 `kzfacev1` 实名 Host/Path 与旧商家配置 | 当前 `sdfaceid` Host/Path/AppCode 契约 | 从可执行配置、接口合同和部署路径移除旧调用路径；历史参考资料保留但禁止回退或混用；按新合同部署和分层验收 |
| 四项固定第三方能力 | 五项固定第三方能力 | 新增 `withdrawal`，默认关闭，按需求解析 |
| 仅收款支付模块 | 提现支付宝证书出款模块 | 收款与出款分别建模，禁止复用收款回调当出款成功依据 |
| 无通用提现闭环 | M-WD-001~M-WD-012 | 引入实名锁名、档位、冻结账本、每日次数、自动/人工出款、查单、退回和审计 |
| 无支付宝证书私有材料 | 四份私有证书材料 + 预检 | 只在启用提现时复制到服务器 Secret 目录，默认通道关闭 |

## 新项目解析要求

- 项目需要提现时，`withdrawal`、`account`、`identity_verification` 必须均为 `resolved_enabled: true`，并有事务型钱包账本；
- 新项目未启用提现时，不得带入任何支付宝出款密钥、App ID 或证书；
- 真实资金测试仍由每个项目所有者明确授权，母版内材料不能替代该授权。

## 旧项目升级边界

运行中的项目不应因升级母版而直接批量改变真实支付/提现行为。先备份、迁移数据、预检证书、跑假网关与对账测试，再在审批窗口分步启用；已存在订单需保留原状态与快照。
