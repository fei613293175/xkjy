# 全局规则索引

完整规则位于《全局强制项目规则_G-001~G-047.md》。所有项目必须完整继承。

| 范围 | 主题 |
|---|---|
| G-001~G-011 | 正式产品、事实源、模块裁剪、服务器、域名与密钥边界 |
| G-012~G-016 | 全项目 Page ID、页面规格、UI 数值、效果图和前后端绑定 |
| G-017~G-021 | 企业级管理后台的易用、可观测、可控和审计 |
| G-022~G-035 | 防漂移、版本、真机、交付、清理和恢复 |
| G-036~G-042 | 标准 API、最小更新、迁移备份、日志健康、配置、幂等与可重复构建 |
| G-043 | 自研图形验证码与匿名接口防刷 |
| G-044~G-045 | 复杂度预算、触发式开发和增量验收 |
| G-046 | 页面返回状态保持、滚动位置恢复与禁止无故重载 |
| G-047 | 专业 SVG 图标体系与禁止文字代图标 |

任何项目包必须在 `RESOLVED_RULESET.yaml` 中列出 G-001~G-047，并验证无缺失。
