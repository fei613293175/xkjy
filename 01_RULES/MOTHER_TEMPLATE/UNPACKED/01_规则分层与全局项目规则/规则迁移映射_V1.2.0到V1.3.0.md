# V1.2.0 → V1.3.0 规则迁移映射

## 一、保持不变

- G-001~G-045 原编号和含义保持不变；
- T-001~T-014、M-ID、M-PAY、M-STORAGE、M-EMAIL、M-ACCOUNT 保持不变；
- 四项固定测试配置原值保留；
- 轻量平台基线、账号安全、页面效果图、企业级后台、服务器、Codex、真机和交付规则继续生效。

## 二、新增全局规则

| 新规则 | 内容 |
|---|---|
| G-046 | 所有平台页面返回时保留滚动、筛选、Tab、分页、草稿和已加载内容，禁止无故重载、回顶和白屏 |
| G-047 | 全项目使用专业 SVG/品牌图标体系，禁止用汉字、字母、数字、Emoji 或 Icon Font 充当图标 |

## 三、新增轻量基线组件

- `LB-PAGE-STATE`：页面状态保持与返回体验；
- `LB-ICON`：专业 SVG 图标体系。

两项均属于轻量全局质量基线，不新增业务页面，不形成重型平台。

## 四、页面规格变化

每个 Page ID 增加：

- `navigation_state`：返回状态、滚动锚点、刷新策略和允许重置的例外；
- `icon_usage`：Icon ID、来源、状态、尺寸、深色模式和无障碍信息。

## 五、兼容原则

执行中的旧项目可以锁定 V1.2.0；新项目统一采用 V1.3.0。旧项目升级时只需补充受影响页面的状态恢复合同和图标登记，不要求无意义地重做全部业务。
