# 统一域名与子域名规则

主域名：`orbexa.cc`

## 规则

1. 每个项目分配唯一、简短、可辨识的项目代码。
2. 子域名必须含项目代码，避免不同项目撞名。
3. 制定项目开发文档时先列出全部子域名，不等开发结束再决定。
4. 项目所有者在正式开发或部署前完成 Cloudflare 解析。
5. 默认开启 Cloudflare 代理；需要直连、WebSocket、文件下载或其他特殊规则时在项目文档注明。
6. 每个子域名写明服务、服务器端口、TLS、回源、健康检查和负责人。

## 推荐

```text
<code>-api.orbexa.cc       API
<code>-admin.orbexa.cc     管理后台
<code>-h5.orbexa.cc        通用 H5（按需）
<code>-yq.orbexa.cc        邀请注册（按需）
<code>-download.orbexa.cc  App 下载（按需）
```

必须维护 `DOMAIN_REGISTRY.yaml`，ChatGPT 在新项目中检查已有登记，不能重复使用其他项目的子域名。
