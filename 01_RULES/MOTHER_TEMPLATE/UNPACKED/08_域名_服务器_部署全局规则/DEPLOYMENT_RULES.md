# 部署规则

1. Codex 使用 `obx-test` 开发和部署。
2. 项目使用唯一根目录、容器名称、网络、数据库名、端口和日志目录，避免与其他项目冲突。
3. 正式结构从第一版开始，用户可见域名和页面不展示测试、Demo 文案。
4. 每次部署前检查现有服务和端口，不破坏其他项目。
5. 配置与代码分离；私有密钥通过服务器运行配置注入。
6. 数据库迁移可追踪、可重复执行，并在版本清单记录。
7. 服务提供健康检查，管理后台显示第三方接口和关键任务状态。
8. 构建产物和部署版本可回滚。
9. 清理旧构建时保留当前版本和必要回滚版本。
10. 项目所有者未解析域名时，可以先完成代码和服务器端口部署，但不得伪报域名已可访问。
