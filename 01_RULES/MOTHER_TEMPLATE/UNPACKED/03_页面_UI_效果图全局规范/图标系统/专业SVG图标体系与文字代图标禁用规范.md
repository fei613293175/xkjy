# 专业 SVG 图标体系与文字代图标禁用规范

> 作用域：全局强制。适用于 Android App、管理后台、H5、效果图和项目交付素材。

## 1. 禁止文字代图标

禁止使用以下内容充当图标：

- 单个汉字，例如“支”“微”“邮”“设”；
- 单个英文字母或缩写，例如“A”“P”“WX”；
- 单个数字、标点或货币符号，例如“1”“+”“￥”；
- Emoji、Unicode 符号；
- Icon Font 字形；
- 在彩色圆形/方形底中放置文字来伪装成图标。

文字可以作为正常标签显示在图标旁，但不能替代图形图标。

## 2. 默认图标方案

### 通用功能图标

默认采用 **Remix Icon SVG** 作为项目基础功能图标库，使用其线性/填充成对风格。一个项目只确定一个主图标族，不得同时混用多套风格明显不同的图标库。

### 第三方品牌图标

支付宝、微信等第三方品牌优先使用官方发布或支付服务商正式提供的品牌图标，保留来源说明。禁止使用“支”“微”“WX”等文字替代。

### 项目专属图标

项目核心业务、底部导航重点入口、特殊等级或独有功能使用项目专属 SVG 图标。图标应表达业务含义，不使用首字母或汉字作为偷懒方案。

### 无官方品牌资产时

使用中性的业务类别图标，例如钱包、二维码、银行卡或移动支付 SVG，并在旁边显示“支付宝”等文字标签。禁止自行绘制易被误认成官方品牌的伪造 Logo。

## 3. 资产管线

```text
设计/选择 SVG 源文件
→ 写入 ICON_REGISTRY.yaml
→ 随项目效果图一并打包实际 SVG
→ Android 转换为 Vector Drawable、ImageVector 或本地 Compose Painter
→ 管理后台和 H5 复用同一 SVG 源
→ 真机和浏览器验收
```

最终项目包必须带上实际使用的图标文件，Codex 不得只看到图标名称后临时随意寻找替代品。

## 4. 文件和登记

推荐目录：

```text
assets/icons/source/
assets/icons/android/
assets/icons/web/
ICON_REGISTRY.yaml
```

每个图标必须登记：

- Icon ID；
- 中文语义和使用场景；
- 功能、品牌、项目专属或装饰角色；
- 来源库、官方品牌来源或设计来源；
- 授权/品牌使用记录；
- SVG 源文件路径；
- Android 资源路径；
- 默认、选中、禁用、错误等状态；
- 尺寸和颜色 Token；
- 深色模式；
- 无障碍标签；
- 使用该图标的 Page ID 和 Component ID。

## 5. 视觉规格

- 常规画布：24 × 24；
- 常用显示尺寸：16、20、24、32 dp；
- 可点击图标最小触控区域：48 × 48 dp；
- 默认状态使用线性图标，选中状态使用填充版本、主色或选中容器；
- 同一层级保持一致的视觉重量、圆角和光学尺寸；
- 图标颜色必须来自 Design Token，品牌图标遵守品牌原色规则；
- 禁止把低清 PNG 放大作为通用功能图标；
- 只有官方品牌资产没有 SVG 时，才允许使用清晰的本地位图资源。

## 6. Android 规则

- 图标必须作为本地矢量资源打包，不依赖运行时远程下载；
- Compose 中统一通过 Icon ID 映射访问，不在页面代码中散落资源名；
- 功能按钮必须提供 `contentDescription` 或等价无障碍描述；
- 纯装饰图标明确标记为装饰，避免读屏重复播报；
- 选中/未选中状态不得只靠颜色，必要时同时改变形态或容器。

## 7. 管理后台与 H5 规则

- 使用本地 SVG 组件或 Sprite，不使用 Icon Font；
- 表格操作、菜单和状态图标统一来源；
- 图标按钮必须提供 Tooltip 和无障碍名称；
- 浏览器缩放和高 DPI 下保持清晰；
- 禁止不同页面分别临时选取不同风格图标。

## 8. 页面文档和效果图要求

每个页面组件使用图标时必须填写 Icon ID，效果图源文件引用与最终代码相同的 SVG。不得在效果图里画一个漂亮图标，开发时改成文字、Emoji 或完全不同的图标。

## 9. 验收标准

- 全项目不存在文字、字母、数字、Emoji 或 Icon Font 充当图标；
- 支付方式等品牌入口使用官方图标或中性类别图标；
- 图标风格、尺寸、对齐和颜色一致；
- 图标在深色模式、禁用状态和高 DPI 下正常；
- Icon Registry、SVG 文件、效果图和代码引用一致；
- 图标按钮具备可理解的无障碍名称。
