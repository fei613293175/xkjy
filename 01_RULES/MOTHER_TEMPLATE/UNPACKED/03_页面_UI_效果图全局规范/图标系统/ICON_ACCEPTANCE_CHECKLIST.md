# 图标体系验收清单

- [ ] 不存在“支”“微”“A”“1”“￥”等文字或符号代图标；
- [ ] 不存在 Emoji 或 Icon Font；
- [ ] 通用功能图标统一来自项目选定的 Remix Icon SVG 体系；
- [ ] 支付宝、微信等使用官方品牌图标，或中性类别图标 + 正常文字标签；
- [ ] 项目专属核心功能使用独立 SVG，而非首字母或汉字；
- [ ] 每个图标均有 Icon ID 和 Registry 记录；
- [ ] 最终项目包包含全部实际使用的 SVG 源文件；
- [ ] Android、管理后台、H5 和效果图使用同一语义图标；
- [ ] 尺寸、光学重量、颜色和选中状态统一；
- [ ] 点击图标触控区域不小于 48 dp；
- [ ] 操作图标有无障碍名称，装饰图标已标记；
- [ ] 深色模式、禁用状态和高 DPI 显示正常；
- [ ] 不存在临时占位图标、模糊位图或页面间风格漂移。
