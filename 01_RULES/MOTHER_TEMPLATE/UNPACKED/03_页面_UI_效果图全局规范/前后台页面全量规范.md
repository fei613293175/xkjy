# 前后台页面全量规范

## 1. 适用范围

- Android App 页面；
- 管理后台页面；
- H5 页面；
- 独立弹窗、抽屉、底部弹层、选择器；
- 页面内部的加载、空数据、错误、成功、禁用、权限不足、审核中、支付中等关键状态。

“后端页面”在本母版中指管理后台可视化页面。纯 API 和任务不生成效果图，但必须有合同和测试。

## 2. Page ID 与 State ID

一个真实路由或独立可复用弹窗使用一个稳定 Page ID：

```text
APP-<MODULE>-<NNN>
ADMIN-<MODULE>-<NNN>
H5-<MODULE>-<NNN>
```

页面内部状态使用 State ID：

```text
DEFAULT
LOADING
EMPTY
ERROR
SUCCESS
DISABLED
```

效果图文件名使用：

```text
<PageID>__<StateID>.png
<PageID>__<StateID>.html
```

禁止把同一路由的加载、空和错误状态虚增为多个 Page ID；必要状态仍必须有独立效果图、源文件和验收记录。图形验证码弹窗属于独立共享 Page ID，可被登录、注册、找回和发送验证码复用。

## 3. 每页页面档案

必须填充 `PAGE_SPEC_TEMPLATE.yaml`，内容包括页面身份、路由、角色、权限、入口出口、业务规则、组件、文案、交互、校验、State ID、API、数据表、配置、日志、埋点、UI 数值、效果图和测试。

## 4. UI 数值要求

每个页面必须显式列出设计宽高、系统栏、顶部栏、底部导航、边距、间距、字号、字重、行高、圆角、控件高度、图标、边框、阴影、色值和响应式断点。Design Token 是唯一全局来源，但页面档案必须写最终解析值。

## 5. 效果图产物

每个 Page ID 的每个必要 State ID 输出 PNG、HTML/CSS/SVG（如有）和 YAML 规格，并更新 PAGE_INDEX 和页面索引。

禁止：

- 多个页面拼成一张图片；
- 只有 PNG 没有源文件；
- 遗漏必要状态；
- 页面、State ID 和文件名不一致；
- 效果图出现项目不存在的功能。


## 6. 页面返回状态保持

所有页面必须执行 G-046。页面档案需声明滚动锚点、筛选、Tab、分页、草稿和已加载内容等返回保留项。进入子页面后返回，不得创建来源页面新实例、回到顶部、白屏或无条件全量请求。需要刷新时保留现有内容后台刷新并局部合并。允许重置的安全或业务例外必须逐页声明。

## 7. 专业图标体系

所有页面必须执行 G-047。通用功能默认使用项目统一的 Remix Icon SVG；品牌入口使用官方品牌资产；项目专属功能使用自定义 SVG。禁止汉字、字母、数字、Emoji、符号和 Icon Font 代替图标。页面规格引用 Icon ID，项目包必须包含实际 SVG 文件。
