# 视觉验收规则

## 必验项目

- 页面整体结构；
- 状态栏、顶部栏、底部栏；
- 字体、字号、字重、行高；
- 色值、渐变、边框和阴影；
- 卡片、按钮、输入框圆角与高度；
- 左右边距、模块间距和对齐；
- 图标类型、Icon ID、尺寸、位置、状态和风格一致性；
- 长文案、空数据、错误和加载状态；
- 键盘弹出、返回、滚动和安全区域；
- 管理后台表格密度、筛选区和详情布局。

## 通过标准

- 关键布局和业务状态不得有语义差异；
- 主要尺寸以页面规格为准，不允许依赖目测随意调整；
- 推荐自动截图差异阈值不高于 2%，并配合人工检查；
- 任何字体过大、布局变形、组件错位、状态缺失或风格不统一均视为未通过；
- 未通过项必须列出 Page ID、State ID、差异、截图和修复结果。


## 页面返回与图标专项

- 深度滚动进入子页面后返回，必须恢复原条目和偏移，不能回顶或白屏；
- 返回时筛选、Tab、分页、草稿和已加载内容按页面合同保持；
- 全项目不得出现文字、字母、数字、Emoji 或 Icon Font 代图标；
- 效果图、SVG 源、Icon Registry 和最终代码使用同一图标语义与资产。
