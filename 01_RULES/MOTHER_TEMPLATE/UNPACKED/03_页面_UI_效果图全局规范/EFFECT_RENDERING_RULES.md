# 确定性效果图生成规则

1. 使用 HTML/CSS/SVG + Design Token 生成，不使用随机生成图作为像素级开发依据。
2. 每个 Page ID 的每个必要 State ID 单独渲染，固定视口、字体、缩放和系统栏参数。
3. 先生成源文件，再统一批量截图为 PNG。
4. App、管理后台和 H5 分别使用固定基准视口。
5. 效果图文案、数据和状态必须来自已确认项目文档。
6. 加载、空、错误、成功和禁用状态使用同一 Page ID 下的 State ID，不重复建立路由。
7. 不在效果图中暴露密钥、真实身份证号、真实支付凭据或调试信息。
8. 页面索引必须支持按平台、模块、版本、Page ID 和 State ID 查询。
9. UI 变更同时更新 Design Token、页面规格、源文件和 PNG。
10. Codex 按 Page ID 开发，真机截图按 `<PageID>__<StateID>` 命名并用于比对。

11. 所有图标必须从 `ICON_REGISTRY.yaml` 引用实际 SVG，禁止在 HTML 中用文字、Emoji、Icon Font 或临时字符代替。
12. 页面源文件应体现返回状态合同所需的长列表、筛选、Tab 等真实布局，便于后续真机状态恢复验收。
