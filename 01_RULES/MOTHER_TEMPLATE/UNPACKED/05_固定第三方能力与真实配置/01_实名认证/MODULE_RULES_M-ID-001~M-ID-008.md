# 实名认证条件模块规则 M-ID-001~M-ID-008

仅在实名认证模块启用时生效。

### M-ID-001 启用边界

仅在 `identity_verification` 被解析为启用时生效。关闭时不得生成实名页面、API、表、后台菜单、配置或测试门禁。

### M-ID-002 基础认证定位与唯一供应商

实名认证定位为基础身份认证，不宣称金融级活体。统一包含姓名、身份证号、前置摄像头随机动作、短视频、清晰照片和第三方人证比对。供应商固定为 `sdfaceid.market.alicloudapi.com/face_id_card/check`，旧 `kzfacev1` 契约禁止使用。

### M-ID-003 免费收费与有效期配置

后台支持免费或收费、价格、支付订单有效期、支付后认证资格有效期、采集次数、动作数量、重试和结果处理默认值。

### M-ID-004 本地零留存与摄像头最小权限

认证照片和视频不得保存到系统相册、共享存储、下载目录或长期本地文件；必要临时文件只允许在 App 私有瞬时缓存并在成功、失败、取消或退出后删除。摄像头只在采集页面的实际采集时段绑定，离页、切后台、完成、失败和取消时立即停止并释放。

### M-ID-005 自动采集与静默上传

首次进入采集页在采集框显示后台配置的倒计时，结束后自动采集，无需再次点击；实际采集结束后停止实时预览并显示业务加载状态。照片和视频静默上传，界面不得显示“上传照片”“上传视频”“OSS”等技术文案。

### M-ID-006 真实接口闭环

必须完成信息保存、媒体采集、对象存储、当前阿里云市场人证比对、`resultCode` 映射、最终状态、失败处理、接口日志和管理后台记录，不得只完成 UI。不得用 HTTP 200、`success=true` 或模拟响应直接判定通过。

### M-ID-007 状态复用与后台管理

已认证用户再次进入入口时必须读取服务器最终状态并直接展示成功页。照片和视频的服务器保留策略分别后台可配；后台提供列表、详情、媒体、供应商订单、分数、结果码、支付、通过/取消/删除等权限化操作、审计和统计。删除记录不得绕过法定留存和关联业务约束。

### M-ID-008 依赖解析

默认依赖 `storage`；保持后台可免费或收费时依赖 `payment`。`withdrawal` 启用时自动启用本模块并要求认证通过后才允许绑定收款账户和提交提现。
