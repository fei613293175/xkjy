# 对象路径与上传管理规则

## 路径

```text
<project_code>/prod/avatar/YYYY/MM/<uuid>.webp
<project_code>/prod/project-images/YYYY/MM/<uuid>.jpg
<project_code>/prod/identity/photos/YYYY/MM/<uuid>.jpg
<project_code>/prod/identity/videos/YYYY/MM/<uuid>.mp4
<project_code>/prod/app-release/YYYY/MM/<version>.apk
```

## 文件状态

```text
UPLOADING
AVAILABLE
BOUND
DELETE_PENDING
DELETED
FAILED
```

## 管理要求

- 业务对象与文件记录建立外键或稳定关联；
- 上传失败不生成可用业务记录；
- 后台可按用户、类型、日期、大小、状态和业务对象搜索；
- 预览实名媒体需要专门权限并写审计；
- 删除操作记录对象键、操作人、原因和结果；
- 只清理无业务绑定且超过宽限期的孤立对象；
- 不用用户原始文件名作为对象键，避免冲突和信息泄露。
