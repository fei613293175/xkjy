# 对象存储条件模块规则 M-STORAGE-001~M-STORAGE-006

仅在对象存储模块启用时生效。

### M-STORAGE-001 启用边界

仅在 storage 被解析为启用时生效。关闭时不得生成 R2 配置、文件管理表、后台菜单或存储测试门禁。

### M-STORAGE-002 真实 R2 配置

启用时使用母版中的 Cloudflare R2 Endpoint、存储桶、自定义域和 S3 凭据完成真实联调。

### M-STORAGE-003 项目路径隔离

每个项目必须使用唯一项目代码和业务类型生成对象路径前缀，禁止不同项目无规则混存。

### M-STORAGE-004 后端持有凭据

R2 管理凭据只允许服务器端使用；Android、管理后台和 H5 不得持有长期密钥。

### M-STORAGE-005 文件业务闭环

必须记录对象键、桶、业务类型、用户、大小、MIME、哈希、状态、创建和删除时间，并实现类型/大小校验、失败处理、业务绑定和删除策略。

### M-STORAGE-006 后台管理和清理

后台提供存储配置、连接测试、文件查询、预览、删除、上传/删除日志、失败记录和孤立文件清理。
