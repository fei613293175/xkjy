# 部署与证书预检

## 目标布局

```text
<project-root>/secrets/alipay-payout/
  private.pem
  app-cert.pem
  alipay-cert.pem
  root-cert.pem
```

部署时将母版 `PRIVATE_CREDENTIALS/alipay-payout` 原子复制到上述目录，目录 `0700`、文件 `0600`，并以只读 Secret 挂载为 `/run/secrets/alipay-payout/*`。

## 运行配置

```text
ALIPAY_PAYOUT_ENABLED=false
ALIPAY_PAYOUT_GATEWAY=https://openapi.alipay.com/gateway.do
ALIPAY_PAYOUT_APP_ID=<PRIVATE_INTEGRATIONS.yaml 中的固定值>
ALIPAY_PAYOUT_PRIVATE_KEY_PATH=/run/secrets/alipay-payout/private.pem
ALIPAY_PAYOUT_APP_CERT_PATH=/run/secrets/alipay-payout/app-cert.pem
ALIPAY_PAYOUT_ALIPAY_CERT_PATH=/run/secrets/alipay-payout/alipay-cert.pem
ALIPAY_PAYOUT_ROOT_CERT_PATH=/run/secrets/alipay-payout/root-cert.pem
ALIPAY_PAYOUT_APP_CERT_SN=<固定值>
ALIPAY_PAYOUT_ROOT_CERT_SN=<固定值>
```

初次部署保持 `ALIPAY_PAYOUT_ENABLED=false`。完成迁移、单元测试、假网关集成、证书预检和后台配置后，再按项目所有者的运营决定开启。业务层自动出款开关与底层通道开关必须同时为真。

## Linux 预检命令语义

实现部署脚本时必须等价执行：

```bash
openssl pkey -in private.pem -noout
openssl x509 -in app-cert.pem -noout -checkend 2592000
openssl x509 -in alipay-cert.pem -noout -checkend 2592000
openssl crl2pkcs7 -nocrl -certfile root-cert.pem | openssl pkcs7 -print_certs -noout
```

再比较私钥导出公钥与应用证书公钥的 DER SHA-256。任何一步失败均停止部署，不开启通道。证书距到期不足 30 天时进入告警，不应静默继续。

`app_cert_sn` 与 `alipay_root_cert_sn` 使用支付宝官方 SDK 从证书文件计算后，与 `PRIVATE_INTEGRATIONS.yaml` 固定值比较；不一致时停止。

## 启动健康状态

后端启动时加载并验证材料，只向内部健康接口返回：

```json
{
  "enabled": false,
  "configured": true,
  "ready": true,
  "mode": "CERTIFICATE",
  "gatewayHost": "openapi.alipay.com",
  "errorCode": null
}
```

不得返回 App ID 之外的秘密、证书正文、文件绝对宿主路径或异常堆栈。
