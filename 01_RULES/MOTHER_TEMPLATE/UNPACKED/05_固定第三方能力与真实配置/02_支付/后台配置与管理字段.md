# 支付后台配置与管理字段

## 设置

- 支付总开关；
- 富运、XApay 商户配置和网关地址（密钥只显示脱敏值）；
- 富运支付宝/微信/USDT、XApay支付宝/微信、支付宝/微信/QQ扫码开关和排序；
- 每种支付方式的说明文字和按订单类型隐藏规则；
- 扫码收款码多文件上传、启停、预览、随机展示和失效时间；
- 原生收银台文案和订单有效期；
- 回调地址；
- 主动查询与重试计划；
- 退款 API 开关；
- 测试连接/查询商户；
- 配置变更历史。

## 按订单类型隐藏方式

每个支付方式维护 `hidden_order_kinds` 数组。收银台列表和服务端发起支付都必须过滤；空数组表示不隐藏。允许值见 `按订单类型隐藏支付方式规范.md`。

## 扫码审核

- 扫码付款审核列表、金额、订单、用户、收款码、截图、提交次数、审核状态；
- 查看原图、通过、拒绝、拒绝理由和操作审计；
- 通过操作必须展示权益和返佣结算结果，禁止直接改订单状态。

## 订单列表

- 本地订单号；
- 第三方订单号；
- 用户；
- 商品；
- 金额；
- 支付方式；
- 状态；
- 创建、支付、过期时间；
- 回调次数；
- 权益发放状态；
- 异常标记；
- 查单、补单、退款入口。

## 详情

- 订单快照；
- 商品和金额计算；
- 用户与业务对象；
- 第三方请求和响应；
- 回调原始参数（脱敏）；
- 验签结果；
- 状态时间线；
- 权益发放记录；
- 主动查询记录；
- 人工操作和审计。
