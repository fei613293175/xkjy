# 支付模块测试矩阵

所有构建、后端测试和部署在 `obx-test`；Android 流程使用状态为 `device` 的真实设备。未获明确授权时只做假网关、签名向量和非资金测试。

| 编号 | 场景 | 期望 |
|---|---|---|
| PAY-01 | XApay支付宝/微信参数与签名向量 | 字段、排序、MD5 小写值一致 |
| PAY-02 | PID/Key 缺失 | 健康检查未就绪，不能发起 |
| PAY-03 | 错签名、错 PID、错金额、错订单 | 回调拒绝，不结算 |
| PAY-04 | 重复回调 | 返回成功，只发一次权益/返佣 |
| PAY-05 | 回调与主动查单并发 | 订单只完成一次 |
| PAY-06 | return_url 显示成功但后端未确认 | UI 保持确认中，不发权益 |
| PAY-07 | 扫码方式无可用收款码 | 返回 `PAYMENT_QR_UNAVAILABLE` |
| PAY-08 | 同方式配置多个收款码连续打开 | 首项随机，全部可左右选择 |
| PAY-09 | 二维码保存、相册/拍照返回 | 页面状态、订单、金额和选择保持 |
| PAY-10 | 截图 MIME/签名/归属/订单不匹配 | 上传或提交拒绝 |
| PAY-11 | 人工审核通过 | 订单、权益、返佣、事件、审计同时成功 |
| PAY-12 | 结算中制造异常 | 事务整体回滚，可安全重试 |
| PAY-13 | 人工审核拒绝后重新提交 | 不发权益，版本递增，新提交可审核 |
| PAY-14 | 两名管理员同时审核 | 一个成功，一个 `VERSION_CONFLICT` |
| PAY-15 | 同订单/截图重复提交 | 唯一约束阻止重复结算 |
| PAY-16 | 后台隐藏某订单类型的某方式 | 指定订单不展示，其他订单正常 |
| PAY-17 | 旧 APK 直接提交已隐藏方式 | 服务端返回 `PAYMENT_METHOD_DISABLED` |
| PAY-18 | 扫码打开/上传/提交绕过隐藏 | 三个入口均拒绝 |
| PAY-19 | 后台重登、服务重启 | 支付开关、说明、排序、隐藏规则保持 |
| PAY-20 | 支付方式说明长文本和字体 1.30 | 不重叠、不裁切，图标与文字对齐 |
| PAY-21 | 在线支付 App 外跳与返回 | 原收银台上下文保持并查询自有后端 |
| PAY-22 | 订单过期、取消、已完成后重试 | 不新结算、不重复支付 |
| PAY-23 | 日志与前端包扫描 | 不含 PID 对应密钥、签名串或付款截图直链 |
| PAY-24 | 原富运支付回归 | 创建、跳转、回调、查单和权益不回归 |

## 交付证据

- 服务器测试命令、时间、版本和结果；
- 假网关请求/响应的脱敏摘要；
- 数据库订单、事件、权益和返佣唯一记录；
- 真机设备序列号、APK 版本、收银台/扫码/订单状态截图；
- 崩溃、ANR 和关键日志检查；
- 未执行真实资金测试时明确写“未执行”，不得用结构测试替代真实到账结论。
