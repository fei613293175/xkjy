# Codex 开始执行

1. 读取 `RESOLVED_RULESET.yaml`，确认 G-001~G-047、`LIGHTWEIGHT_COMPLETE` 和启用的 M 模块；
2. 读取 `PROJECT_CONTEXT`、`CURRENT_RELEASE`、`FEATURE_MATRIX`、`PAGE_INDEX`、页面状态合同、`ICON_REGISTRY` 和 `RELEASE_MANIFEST`；
3. 只实现已启用模块和当前 `/goal`，未触发平台模块不得开发；
4. 账号模块启用时，必须完整实现注册、登录、找回、会话、账号后台以及自研图形验证码；禁止使用第三方验证码或只在前端做假校验；
5. 管理后台登录始终使用自研图形验证码、后端票据校验和频控；
6. 固定第三方能力启用时，直接使用项目包内私有配置，由后端调用；实名认证禁止旧供应商地址；
7. 支付启用时读取 payment 全部合同，按已解析 profile 实现富运、XApay支付宝/微信、支付宝/微信/QQ扫码审核、统一权益/返佣结算和订单类型隐藏双重校验；商户密钥不得进入客户端；
8. 提现启用时使用随包支付宝证书模式、资金状态机、查单对账和冻结账本；真实转账必须获得本项目明确授权；
9. 所有开发、构建、部署和非设备测试在 `obx-test` 完成，本机不搭建环境；
10. 所有页面返回时保留滚动、Tab、筛选、分页、草稿和已加载内容，不得回顶、白屏或无条件重新加载；
11. 所有图标严格按 `ICON_REGISTRY.yaml` 和随包 SVG 实现，禁止文字、Emoji、符号和 Icon Font 代图标；
12. 优先完成核心业务闭环和必要后台，不建设未触发的重型平台；
13. 本版本新增、修改和受影响页面完整测试，阶段/最终版本再全量回归；
14. Android 交付前使用空闲真机安装、操作、检查日志，验证页面状态恢复并截图对比图标和视觉；
15. 输出 APK、中文功能对比、测试报告、视觉报告和项目所有者测试说明到桌面；
16. 完成 `/goal` 后更新状态并停止扩展。
