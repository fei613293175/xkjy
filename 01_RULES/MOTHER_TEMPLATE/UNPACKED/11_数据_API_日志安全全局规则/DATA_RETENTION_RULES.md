# 数据与构建产物保留规则

## 构建和交付物

- 本机最多保留最近 2 份旧构建交付物；
- 服务器最多保留最近 5 份旧构建交付物；
- 可清理 Gradle 缓存、临时截图、旧 ZIP、旧 APK 和无用构建目录；
- 保留当前版本和必要回滚版本。

## 正式业务数据

正式用户、订单、支付、实名结果、配置历史和审计日志不属于“无用历史数据”，必须按项目业务和后台配置管理，不得套用 2/5 份构建清理规则。

## 实名媒体

照片和视频是否服务器保留、保留期限和删除任务由后台配置；App 本地不持久保存。

## 清理证据

每次自动或人工清理记录：对象类型、范围、数量、原因、执行人/任务、开始和完成时间、失败项。


## 验证码和会话临时数据

图形验证码 challenge、captcha_ticket、业务验证码和找回令牌均按短时有效期自动清理，不作为长期业务档案。会话记录按项目安全和审计需求保留，Refresh Token 只保存不可逆摘要。
