# 私有密钥使用规则

1. 母版和私有项目包允许按项目所有者要求保留明文测试值。
2. ChatGPT 不得在普通回复中重复打印全部密钥，只生成私有文件。
3. 只把 `RESOLVED_RULESET` 中已启用模块所需配置复制到项目包。
4. Codex 将值写入服务器运行配置。
5. 不允许硬编码到 Android、管理后台前端和 H5。
6. 公开仓库必须忽略私有配置文件。
7. 日志、测试报告和错误页面必须脱敏。
8. 后台查看密钥默认掩码，并受权限、二次确认和审计控制。
9. 更换密钥时更新项目私有配置和服务器，不修改业务代码。
10. 接口失败先记录 HTTP 状态、供应商错误码、时间和调用 ID，不以猜测代替证据。
11. 关闭模块的凭据不得进入当前项目运行配置，也不得成为交付检查项。

12. 验证码 HMAC、会话签名和 CSRF 等项目内部安全密钥由 Codex 在服务器首次初始化时自动生成，按项目稳定保留，不得向用户重复索取，也不得在每次构建时重新生成。
13. 支付宝私钥和证书只允许以服务器 Secret 文件使用，禁止写入数据库、`.env` 明文值或后台配置表单；`.env` 只保存受限容器内路径和证书序列号。
14. 提现关闭时不得将支付宝材料复制到项目包；提现启用时必须按 `0600` 文件、只读挂载、启动预检和证书到期告警部署。
15. 提现姓名/账号密文使用项目独立 `WITHDRAWAL_ENCRYPTION_KEY`，禁止使用支付宝应用私钥或通用登录签名密钥。
16. 真实资金测试属于不可逆外部操作，必须获得当前项目明确的收款人和金额上限授权；证书校验通过本身不授权转账。
