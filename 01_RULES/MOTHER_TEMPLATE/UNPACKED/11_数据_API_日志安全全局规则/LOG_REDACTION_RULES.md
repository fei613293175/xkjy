# 日志脱敏规则

不得记录完整：

- AppCode、AppSecret、商户密钥、R2 Secret、SMTP 密码；
- 身份证号；
- 人脸 Base64、照片和视频内容；
- 邮箱/短信业务验证码、图形验证码答案；
- 密码、Access Token、Refresh Token、captcha_ticket、找回密码令牌；
- 支付买家完整账号；
- 带密钥的完整查询 URL。

推荐显示：

- 密钥：前 4 位 + `****` + 后 4 位；
- 身份证：前 6 位 + `********` + 后 4 位；
- 邮箱：部分掩码；
- 第三方请求：记录调用 ID、接口名、状态、耗时和脱敏错误。
