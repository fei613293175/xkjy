# 账号模块测试清单

- [ ] 密码登录点击提交后弹出图形验证码，表单内容不丢失；
- [ ] 验证码正确后自动继续登录，无需再次点击；
- [ ] 验证码登录的“发送业务验证码”和“最终登录”分别要求新的图形验证码；
- [ ] 注册的“发送业务验证码”和“最终注册”分别要求新的图形验证码；
- [ ] 找回密码请求和最终重置分别要求新的图形验证码；
- [ ] 验证码错误、过期、刷新、三次失败和频控状态正确；
- [ ] 直接绕过弹窗调用登录、注册、找回、重置或发送验证码 API 被后端拒绝；
- [ ] 同一票据重复使用、跨用途使用、跨目标使用和并发重放均被拒绝；
- [ ] 验证码答案、图片内容和业务验证码未进入日志；
- [ ] 登录失败不泄露账号是否存在；
- [ ] 注册重复账号被唯一约束和事务阻止；
- [ ] 邮箱/短信验证码频控、有效期、错误次数和一次性正确；
- [ ] 找回密码对存在和不存在账号返回一致外部提示；
- [ ] 重置令牌只能使用一次；
- [ ] Access Token 过期后可刷新，Refresh Token 正确轮换和撤销；
- [ ] 退出当前设备、全部设备和后台强制下线生效；
- [ ] 冻结、解封、密码修改和注销在 App 生效并有审计；
- [ ] 管理后台每次登录提交使用图形验证码、频控和安全会话；
- [ ] Cookie 鉴权后台的写请求通过 CSRF 测试；
- [ ] 所有已启用账号页面、弹窗和后台页面具备 Page ID、效果图和真机/浏览器测试证据。
