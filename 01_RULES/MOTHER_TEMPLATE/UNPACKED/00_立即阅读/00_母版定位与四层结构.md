# 母版定位与四层结构

本包是私有项目开发母版，不是某一个 App 的开发文档。

## 核心组成

1. **五项固定第三方能力**：当前可用实名认证、富运/XApay在线支付、支付宝/微信/QQ扫码审核支付、Cloudflare R2、SMTP 邮箱、提现与支付宝证书出款，含私有配置和离线合同；
2. **轻量平台基线**：API、更新、迁移备份、日志健康、最小配置、幂等、构建、自研图形验证码、页面状态保持、专业 SVG 图标和复杂度预算；
3. **可选平台模块**：账号、注册、登录、找回密码和会话；
4. **整个项目全局规则**：全部页面、UI、效果图、企业级后台、服务器、Codex、真机、测试和交付。

## 规则层级

- T：ChatGPT 整合规则；
- G：整个项目始终生效，G-001~G-047；
- M：启用模块条件生效；
- P：具体项目专属需求。

账号模块不是所有项目强制业务；项目没有普通用户账号时不生成 App 登录、注册和找回页面。提现启用时因实名锁名和账户归属自动启用账号与实名认证，并要求事务型钱包账本。自研图形验证码是轻量安全基线，管理后台登录始终使用，App 存在登录、注册、找回或验证码发送时自动应用。

所有页面返回时必须保持离开前的滚动、筛选、Tab、分页、草稿和已加载内容，禁止无故回顶、白屏和重新加载。所有项目统一建立专业 SVG 图标体系，禁止用汉字、字母、数字、Emoji 或 Icon Font 代替图标。

本母版不设计具体项目效果图。新项目需求确认后，对整个项目所有 Page ID 生成独立效果图、实际 SVG 图标和源文件。
