# 版本说明与变更记录

## V1.4.2｜XApay与扫码支付完整整合版｜2026-08-16

1. 完整复制 V1.4.1 基线；实名认证、R2、SMTP、提现、账号、全局规则、历史参考资料和支付宝证书材料保持继承，不做删减或覆盖。
2. 在同一个 payment 模块内加入 XApay 支付宝/微信在线支付合同，固定 PID、密钥、网关、查单、回调和返回地址只存于私有服务器配置。
3. 加入支付宝、微信、QQ 人工扫码支付合同：后台维护多个收款码，前端随机展示并支持横向选择、保存图片、上传付款截图，后台审核通过后走统一权益和返佣结算。
4. 加入按订单类型隐藏支付方式的后台配置和服务端双重过滤，支持会员、幸运卡、虚拟权益、头条卡、置顶卡、刷新卡、变色卡、实名认证等订单类型。
5. 增加支付 API 合同、数据结构、状态机扩展、后台字段和测试矩阵；保留富运历史合同，不把 XApay 在线 QQ 虚构为已确认能力，QQ 以人工扫码方式提供。
6. 本版本仅更新支付相关文件、母版版本索引和支付私有配置；非支付文件按基线复制并通过哈希复核。

## V1.4.0｜实名认证与提现通用能力版｜2026-08-16

1. 替换 V1.3.0 中不适用于当前套餐的实名认证供应商契约；唯一可执行地址为 `https://sdfaceid.market.alicloudapi.com/face_id_card/check`，使用 AppCode 和标准表单编码。
2. 移除旧商家实名地址、旧辅助凭据、截图和示例代码作为当前事实源；旧路径只在迁移说明中作为禁止回退的历史标识出现。
3. 实名模块补充倒计时自动采集、摄像头最小启用时段、采集结束停止实时画面、已认证再次进入直达成功页，以及供应商异常的独立状态。
4. 新增第五项固定能力 `withdrawal`，规则范围 `M-WD-001~M-WD-012`，默认关闭、按需求解析。
5. 提现模块包含实名锁名、固定档位、两位小数金额、余额冻结、每日最多次数、自动阈值出款、人工审核后一键接口出款、查单对账、失败退回和审计。
6. 新增支付宝 RSA2 证书模式合同、启动预检、私钥/应用证书匹配、原始响应验签、定时对账和假网关测试要求。
7. 按项目所有者明确要求，随私有模板打包当前应用的私钥、应用证书、支付宝证书和根证书；只在项目启用提现时复制到服务器受限 Secret 目录。
8. 新增提现数据独立加密密钥模板，禁止将支付宝私钥用于数据库加密、APK、H5 或后台前端。
9. 更新模块目录、触发矩阵、解析规则、ChatGPT/Codex 指令、运行配置、交付清单和安全边界；无需再读取旧插件分析方案。
10. 证书结构和技术方案可复用不代表支付宝权限、证书有效期、账户余额、限额或风控永久可用；真实资金测试仍必须取得每个项目的明确授权。
