# 一分钟使用流程

1. 上传本母版 ZIP 和新项目需求；
2. 说明项目核心业务和是否需要普通用户账号；
3. 选择实名认证、支付、对象存储、邮箱、提现五项固定第三方能力；支付启用时直接勾选富运在线、XApay在线和/或人工扫码 profile；
4. ChatGPT 自动应用 G-001~G-047、轻量基线和自研图形验证码；
5. 项目需要账号时自动加入注册、登录、找回、会话和账号后台；
6. 为每个 Page ID 制定返回状态合同，并建立 Icon Registry 和实际 SVG 资产；
7. 需求确认后生成全项目 Page ID、效果图和完整开发包；
8. 把项目包交给 Codex，在 obx-test 开发并用真机验收页面状态恢复、图标和全部业务。

已存在的实名认证接口、富运/XApay支付配置、扫码审核方案、密钥、支付宝证书、域名、服务器和测试规则不需要再次提供。提现启用时 ChatGPT 自动带入证书出款方案，但真实资金测试仍需每个项目单独明确授权收款人与金额上限。
