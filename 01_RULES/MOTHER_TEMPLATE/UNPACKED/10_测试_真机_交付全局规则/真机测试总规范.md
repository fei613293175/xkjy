# Android 真机测试总规范

## 设备

- 本机已有 3 台 Android 真机；
- 使用本机已有 ADB；
- 测试前 `adb devices` 中目标设备状态必须严格为 `device`；
- 选择空闲设备，其他设备占用时不必一直等待固定某一台；
- 不可用时停止设备测试或排队，不得改用模拟器；
- 可以安装 ADB 专用输入法。

## 测试内容

1. 安装 APK；
2. 首次启动、权限、登录和基础导航；
3. 每个新增或修改 Page ID 的点击、输入、返回、滚动，以及必要 State ID；
4. 关键业务完整流程；
5. 真实第三方接口联调；
6. 崩溃、ANR、应用日志和网络错误；
7. 不同设备尺寸的关键页面；
8. 逐页截图和效果图视觉比对；
9. App 切后台、支付后返回、进程恢复等生命周期；
10. 实名媒体不进入相册和共享存储；
11. 原生收银台和外部支付跳转边界；
12. 登录、注册、找回和验证码发送的图形验证码弹窗、刷新、错误、过期和后端防绕过；
13. 深度滚动、筛选、Tab、分页和表单状态在进入子页面后返回时保持，不回顶、不白屏、不重复全量加载；
14. 从支付 App、相机、相册、文件选择器和权限页面返回时原页面上下文保持；
15. 全项目图标检查：禁止文字、字母、数字、Emoji 和 Icon Font 代图标，SVG/品牌图标与 Icon Registry 一致。

## 证据

- 设备序列号和系统版本；
- APK 文件、版本和 SHA256；
- 测试时间；
- 测试账号；
- 测试路径；
- Page ID + State ID 截图；
- 日志摘要；
- 问题、修复和复测结果。

## 结束

释放设备占用并执行返回主界面，保证其他项目可使用。


## 增量与全量范围

- 小版本：新增、修改和受影响页面完整测试，未修改主流程做冒烟；
- 阶段版本和最终版本：全量 Page ID、必要 State ID、关键业务和视觉回归。
